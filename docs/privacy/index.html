Privacy policy

Last updated: July 29, 2026

Overview

Buttonizer is designed to work locally in your browser.

The extension does not require an account, does not use analytics, does not send captured button data to external servers, and does not sell or share personal data.

What data the extension accesses

When you trigger a scan on the active page, Buttonizer reads limited page data needed to identify visible button-like elements.

  • button text or accessible label
  • button HTML snippet
  • button selector information
  • computed visual styles such as font, colors, border radius, border, and shadow
  • the current page title and hostname

This information is used only to show button previews in the popup and to save records you explicitly choose to keep.

What data the extension stores

Buttonizer stores saved button snapshots locally in chrome.storage.local.

Stored records may include button metadata, style values, page hostname, page title, selector information, and the saved timestamp.

What the extension does not do

Buttonizer does not:

  • collect account details
  • collect payment information
  • collect browsing history outside the page you actively scan
  • send captured component data to remote servers
  • track keystrokes
  • send telemetry or analytics events
  • sell personal information

Permissions and why they are needed

activeTab is used to inspect the current tab only after you trigger a scan.

scripting is used to run a button-detection script in the active page.

storage is used to save your button library locally in the browser.

Data sharing

Buttonizer does not share saved button data with third parties.
